## VoBoost - Підсилення звуку

Плагін для **Lampa**. Дозволяє підняти гучність вище 100%, щоб «розігнати» надто тихі відео.

### Що робить

- Додає прямо в плеєр (меню налаштувань - шестерня) пункт **«Підсилення звуку (буст)»** зі значеннями від 100% до 500% - рівень можна змінювати на льоту під час перегляду.
- Підсилює звук через Web Audio API (`GainNode`): підсумкова гучність = штатний повзунок (0-100%) × буст.
- Застосовує вибране значення миттєво та показує компактний індикатор гучності поверх відео.
- Несумісний з вбудованою нормалізацією звуку - якщо вона ввімкнена, плагін один раз попередить про це.

### Обмеження

- Працює лише у вбудованому (HTML5) плеєрі.

### Встановлення

- Налаштування > Розширення > https://nrsua.github.io/lampa-nrs/voboost.js

## LParty - Спільний перегляд

Плагін для **Lampa**. Дозволяє дивитися одне й те саме синхронно з друзями на різних пристроях.

### Що робить

- Додає іконку в шапці та пункт **«Відкрити список кімнат»** у налаштуваннях - показує відкриті кімнати, дозволяє створити свою або зайти за кодом.
- Синхронізує відтворення з хостом: пауза, продовження та перемотка повторюються в усіх глядачів. Дрібні розбіжності підганяються плавною зміною швидкості відтворення, великі - точною перемоткою.
- Кімнату можна створити з посилання (m3u8 / mp4) або прямо плеєра - пункт **«LParty - Дивитися з друзями»**: запускаєте відтворення, і кімната створюється автоматично на поточний потік.
- Кімната може бути публічною (видно в списку) або доступною лише за кодом, за бажанням - з паролем.
- Показує поверх плеєра бейдж із назвою кімнати, її кодом і кількістю глядачів; при наведенні розгортається панель діагностики.
- Сповіщає, хто приєднався, вийшов, поставив паузу чи перемотав.
- Якщо хост виходить, роль хоста автоматично переходить до одного з глядачів, і перегляд продовжується.
- Коли хост перемикає серію, кімната переїжджає на новий потік разом з усіма.

### Як це працює

- Обмін даними йде через WebSocket-реле (за замовчуванням `wss://itty.ws/c/`), власний сервер не потрібен. Назва каналу кімнати - хеш коду й пароля, тож реле не бачить, до чого ви підключаєтесь.

### Обмеження

- Синхронізується стан відтворення, а не саме відео - потік кожен отримує сам, тож усі учасники мають мати доступ до того самого посилання.
- Працює у вбудованому (HTML5) плеєрі.

### Стабільність

- Основне тестування відбувалося з онлайн плагіном - https://lampame.github.io/main/bo.js

### Встановлення

- Налаштування > Розширення > https://nrsua.github.io/lampa-nrs/lparty.js

## LampaDBLink - Синхронізація між пристроями

Плагін для **Lampa**. Тримає закладки, таймкоди, плагіни та профілі однаковими на всіх ваших пристроях через власну базу **Supabase**.

### Що робить

- Синхронізує обране й закладки, історію перегляду та таймкоди, список плагінів і налаштування Lampa - усе зберігається у вашому проєкті Supabase, без сторонніх серверів.
- Додає пункт **LampaDBLink** у головне меню - хаб синхронізації з вкладками **«Пристрої»** та **«Профілі»**.
- Профілі: створення, перемикання, перейменування та видалення. У кожного профілю власні закладки, таймкоди й набір плагінів; швидке перемикання - кнопка з аватаром у шапці.
- Менеджер плагінів: додати, прибрати або тимчасово вимкнути плагін для профілю - зміни розлітаються на всі пристрої.
- **«Відкрити на пристрої»** - з контекстного меню картки або з панелі плеєра надсилає фільм на інший ваш пристрій, щоб продовжити перегляд на ньому.
- Показує, які пристрої зараз онлайн, і дозволяє їх перейменувати.
- Резервна копія: вивантаження даних пристрою в базу та відновлення з неї.
- Імпорт з Cub: переносить профілі, закладки та плагіни з облікового запису Lampa.

### Встановлення

1. Налаштування > Розширення > https://nrsua.github.io/lampa-nrs/LampaDBLink.js
2. Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
3. Налаштування > LampaDBLink > **З'єднання**: вкажіть Project URL і Publishable key (`sb_publishable_...` або старий `anon public`) з Project Settings > API Keys.
4. Натисніть **«Перевірити підключення»**. Першого разу плагін покаже невеликий SQL - скопіюйте його, виконайте в Supabase SQL Editor і повторіть перевірку. Решту таблиць плагін створить сам.
5. Увімкніть синхронізацію в розділі **«Синхронізація»** і повторіть кроки 3-4 на інших пристроях, вказавши той самий проєкт.

### Основний розробник

- Основою цього плагіна став - https://lampame.github.io/main/GramLink/GramLink.js

### Обмеження

- Потрібен власний проєкт Supabase - без URL і ключа плагін не працює.
- Використовуйте лише publishable / anon key. **Ніколи** не вписуйте `sb_secret` або `service_role` - плагін працює на клієнті, і ключ буде видно.
- Схема створюється з відкритим доступом для anon, тому база розрахована на приватне використання: не публікуйте ключ і не діліться проєктом.
- Налаштування самого пристрою (плеєр, субтитри, інтерфейс, кеш) навмисно лишаються локальними - синхронізуються дані, а не вигляд кожного пристрою.
